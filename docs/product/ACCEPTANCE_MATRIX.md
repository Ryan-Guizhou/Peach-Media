## HTML 原型专用验收（现在即可执行）

| 用例 | 步骤 | 预期 |
|---|---|---|
| UI-01 | 打开 `prototype/index.html` | 显示中文工作台、真实风格示例数据、DEMO 标识 |
| UI-02 | 切换左侧导航全部模块 | 每个页面有内容和有效导航，不出现空白错误 |
| UI-03 | 切换演示租户 | 资产、任务、Open API Key、组织等按租户过滤 |
| UI-04 | 资产搜索/类型筛选/网格切换 | 结果随输入变化，详情可查看/编辑/删除 |
| UI-05 | 浏览器选择文件上传 | 仅显示模拟进度、创建本地 Asset + Job；不发送网络请求 |
| UI-06 | 创建任务、推进、取消/重试 | 状态遵守允许转换，任务归属为当前租户 |
| UI-07 | 新建/暂停工作流、触发 | 产生可查看的模拟任务，不启动真实容器 |
| UI-08 | 切换 Docker/Kubernetes 视图、启停 Worker | 只改变演示 Worker 状态，明确非真实执行 |
| UI-09 | 新增 API Key/Webhook、测试回调 | 本地状态变化，API Key 的明文仅创建时可见 |
| UI-10 | 数据上报、签名链接、用量、审计 | 事件入本地列表，签名链接标为无效示例 |
| UI-11 | 刷新/关闭再打开 | 演示状态可从浏览器 localStorage 恢复 |
| UI-12 | 设置页重置数据 | 完整恢复初始 Fixture，浏览器没有真实数据丢失 |
| UI-13 | 手机窄屏、键盘导航、ESC 关闭对话框 | 主功能可用，内容不无限横向溢出 |

**自动化入口：** `node --test tests/*.test.cjs` 验证纯状态模型与 HTML 结构；将来引入浏览器级 Playwright E2E（不作为原型运行依赖）。

## 三入口独立性补充验收（FR-137～FR-144）

| 用例 | 企业控制台 | 开发者平台 | Open API | 预期 |
|---|---|---|---|---|
| AC-ENT-01 | `/console/` | `/developers/` | `/openapi/v1/*` | 各自独立入口可访问，不以同一 SPA 侧栏混放 |
| AC-ENT-02 | 资产/任务/用量模块 | 创建并只显示一次演示 Key | 该 Key 可授权调用 `/assets` | Key 只属于当前 tenant/scopes；403/404/401 有区分 |
| AC-ENT-03 | 同步查看外部 API 资产和活动 | 读取 API 活动、调用量 | 上传会话→Complete→Job→事件→用量 | 本地 Mock 服务展示跨入口闭环（非生产后端） |
| AC-ENT-04 | 定时任务仍有独立管理页 | 无内部调度框架绑定 | 外部调用无需 RPC 客户端 | 方案、文档、UI 中不引用 外部 RPC 调度组件；内部服务采用 OpenFeign |
| AC-ENT-05 | 切换租户后仅见授权资产 | Key 所属租户不可改 | 其他租户资源请求返回 404 | 严格数据隔离与后端强制授权 |
